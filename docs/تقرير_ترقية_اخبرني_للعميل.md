## 2. ما تم إنجازه

### 2.1 ترقية Laravel 13

- تحديث هيكل Laravel 13: `bootstrap/app.php`، `bootstrap/providers.php`، `artisan`، `public/index.php`
- نقل المسارات (Routes) والمتحكمات (Controllers) والنماذج (Models)
- تحديث `composer.json` / `composer.lock`
- إزالة الملفات القديمة التي استبدلها Laravel 13 (Kernel، Middleware القديمة، Providers القديمة)
- الحفاظ على جميع مسارات الـ API والـ AJAX كما هي (بما في ذلك اختلافات حالة الأحرف في بعض الروابط)

### 2.2 اختبارات ضمان الجودة

تم إنشاء **33 اختبار عقد** — اختبار واحد لكل مسار موثّق في `API_INVENTORY.md`:

- تسجيل الدخول / التسجيل / استعادة كلمة المرور
- الصفحة الرئيسية والملف الشخصي وإرسال الرسائل
- لوحة المستخدم والإعدادات والإشعارات
- جميع نقاط AJAX (14 نقطة)
- **النتيجة:** 33 ناجح، 0 فاشل، 98 assertion

اختبارات إضافية لـ Firebase FCM HTTP v1: **9 ناجح، 30 assertion**

**المجموع:** 42 اختبار، 128 assertion — جميعها ناجحة

### 2.3 تحسينات الأداء (بدون تغيير السلوك)

| # | التحسين | النتيجة |
|---|---------|---------|
| 1 | تحميل مسبق لردود المنشورات (Eager Load) | −10 استعلامات على `/user` |
| 2 | دمج استعلامات المنشورات المتداخلة | −2 استعلامات |
| 3 | تخزين مؤقت لعدّاد الرسائل غير المقروءة | −1 استعلام |
| 4a | إزالة تكرار استعلام التصويت في الملف الشخصي | −1 استعلام لكل استطلاع |
| 4b | دمج COUNT + SELECT للمستخدم | −1 استعلام لكل طلب ملف/رسالة |
| 5 | فهارس قاعدة البيانات المركّبة | تحسين زمن الاستعلام عند التوسع |

**GET `/user`:** من **18 استعلام / ~20 ms** → **5 استعلامات / ~10 ms**  
**GET `/{username}`:** من **12 استعلام / ~8 ms** → **4 استعلامات / ~5 ms**

### 2.4 ترقية Firebase (FCM HTTP v1)

- استبدال واجهة FCM القديمة (متوقفة من Google منذ 2024) بـ **FCM HTTP v1**
- المصادقة: OAuth 2.0 عبر Service Account (متغيرات البيئة)
- **الإرسال متزامن** (بدون Queue) — كما طُلب للحفاظ على السلوك
- المحتوى محفوظ: «لديك رسالة جديدة» — العنوان والنص والأيقونة
- فشل الإشعار **لا يمنع** حفظ الرسالة أو رسالة النجاح للمرسل

### 2.5 فهارس قاعدة البيانات (Migration آمن)

- `posts(user_id, is_read, type)` — شارة الرسائل غير المقروءة
- `answers(user_id, post_id)` — فحص التصويت والرد المكرر
- Migration **إضافي فقط** — قابل للعكس، بدون حذف بيانات

### 4.2 الخادم

- **Nginx** — جذر المستند: `public/`
- **PHP 8.4-FPM**
- **MySQL 8**
- **OPcache** مفعّل
- صلاحيات الكتابة: `storage/`، `bootstrap/cache/`، `public/images/profile/`
- **نسخة احتياطية** لقاعدة البيانات قبل `php artisan migrate`

### 4.3 أوامر النشر (عند الموافقة)

```bash

php artisan config:cache
php artisan route:cache
```
